Статический одностраничный сайт для GitHub Pages.

## Структура

- `index.html` — разметка и тексты
- `styles.css` — оформление и адаптив
- `script.js` — меню, FAQ, отзывы и просмотр дипломов
- `main.jpg` — главное фото
- `assets/images/diplomas` — сжатые превью дипломов
- `diploma-*.jpg` — полноразмерные изображения для просмотра
